# Breach Point

A browser tactical shooter (three.js + cannon-es) with a layered-anatomy damage model.

## Play
Open the GitHub Pages link for this repo.

## Install on iPhone
1. Open the link in **Safari**.
2. Tap **Share** then **Add to Home Screen**.
3. Launch it from the new icon: it runs full screen and works offline after the first load.

On Android (Chrome): menu then **Install app**.

## Saving
Progress (tokens, unlocks, loadout, variants, skills) and settings are saved on the device. Reset them in Character, Progress.

## Updating
Replace `index.html`, then bump `VERSION` in `sw.js` so installed copies refresh.
